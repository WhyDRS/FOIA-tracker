# DTC Tokenization Services no-action FOIA drafts

These drafts target records the SEC receives or maintains under the December 11, 2025 Division of Trading and Markets no-action letter concerning DTC's Preliminary Base Version of the DTCC Tokenization Services:

https://www.sec.gov/files/tm/no-action/dtc-nal-121125.pdf

The requests are separated so the clean quarterly-report request can be processed independently from incident, change-control, and staff-request records.

Files:

- `quarterly-report-packages.md` - the recurring quarterly packages required by representation 10, including the aggregate amount and value of Tokenized Entitlements outstanding at quarter-end.
- `systems-events-and-tier-2.md` - Systems Event notices, updates, resolution notices, and final factual records in SEC possession concerning the Tier 2-or-better status of LedgerScan and Factory.
- `representation-change-notices.md` - notices and related records concerning changes to the representations on which the no-action relief is based.
- `division-data-requests.md` - Division staff requests for DTC system information or data under representation 16 and DTC's responses.

Each draft is written as a reusable request covering responsive records through the date the SEC performs its search. No SEC tracking number should be assigned in this repository until the request is actually submitted and acknowledged.
